# Secure Password Validation and Hashing System

A robust, web-based **Secure Password Validation and Hashing System** built using the **Flask** microframework and Python's native cryptographic libraries. This application enforces strict user password policies, safely handles data encoding, logs security policy violations, and implements irreversible cryptographic storage using the industry-standard **SHA-256 algorithm**.

---

## 🚀 Key Features

* **Strict Input Validation**: Enforces complex password policies requiring specific lengths and combinations of uppercase letters, lowercase letters, numbers, and special characters.
* **Cryptographic Hashing**: Valid passwords are instantly encrypted using the **SHA-256 algorithm** via Python's `hashlib` before storage. Plain-text passwords are never saved on the server.
* **Intrusion & Failure Logging**: Invalid password attempts are intercepted, tracked, and stored inside a structured blacklist (`blocked_password.txt`) to simulate access control auditing.
* **Dynamic Web UI**: Powered by a clean, modern user interface built with HTML5, CSS3, and Flask's **Jinja2 rendering engine** to provide immediate, contextual alert messaging to users.

---

## 🛠️ Technology Stack

* **Backend Framework:** Flask (Python)
* * **Frontend Architecture:** HTML5, CSS3, Jinja2 Templates
* **Security & Encryption:** Cryptographic Hashing (`hashlib` - SHA-256)
* **Storage Layer:** Flat-file text-based logging (`.txt`)

---
## 🔒 Implemented Security Rules

When a password is submitted, it is run through a cascading validation checkpoint system:

1. **Length Floor**: Minimum length of **8 characters**.
2. **Length Ceiling**: Maximum length of **12 characters**.
3. **Casing Verification**: Must include at least one **Uppercase** and one **Lowercase** character.
4. **Numeric Integrity**: Must contain at least one **Digit** (`0-9`).
5. **Special Signatures**: Must contain at least one character from a predefined set of **Special Symbols** (`!@#$%^&*()-_=+[]{}|;:'\",.<>?/`).
